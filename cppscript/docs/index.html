CppScript 语法规范 v14.2（完整版）

语言：CppScript　｜　版本：v14.2　｜　规则文件：任意文本（≤ 100 KB）

面向 C++ 用户，无编译期、无指针、无宏；容器（含 list/multiset/multimap）与 <algorithm> / <cmath> / <cstdio> 风格函数可直接使用（无 #include）。

前端：输入/输出框仅在真正执行到 in/out 等时出现；key/query 若代码可能用到且参数未在 URL 中，会先显示并需点「确认并运行」（可留空）。 源文件建议使用后缀 .cpps（如 rule.cpps）。通过 ?url= 加载时不要求文件名必须是 .cpps，只要响应是纯文本源码即可。

核心：out() 输出 body（可边执行边显示）；return 可返回跳转 URL 或状态码。

运行方式两套：

  • Cloudflare Worker（/?url=...）：服务端执行，出站 get/post 不受浏览器 CORS 限制。
  • 纯前端（同目录 根目录 index.html）：浏览器内解析执行，不依赖 Worker；跨站请求受 CORS 限制。

v14.2 要点：auto main；key 花括号下标；with 整式绑定；关键字不可作变量名；deque/set/map 为类型关键字；容器无初值即空容器；Worker 按需 key/in 表单；out 流式（TransformStream）；纯前端 根目录 index.html；algorithm 风格函数。

1. 基础

1.1 文件结构

  • 单个 UTF-8 文本（不要求扩展名是 .txt，.md .json .rule 都可以）
  • 通过 ?url= 拉取，大小 ≤ 100 KB
  • 语句以 ; 分隔
  • 标识符 [A-Za-z_][A-Za-z0-9_]*，区分大小写
  • 注释：// 单行、/* 多行（不嵌套） */
  • 关键字、类型名小写

1.2 版本号

文件顶部可选：

// dsl: 14
  • 不写 → 默认按最新版本（当前 v14）解析
  • 写了不支持的版本（如 // dsl: 99）→ E41

1.3 关键字

number  string  bool  auto  void  struct
deque  list  set  multiset  map  multimap  pair  tuple
if  else  switch  case  default
for  while  break  continue
return  delete  in  out  getchar
true  false
with  param  header  proxy  UA
try  catch  throw

类型名 deque / list / set / multiset / map / multimap / pair / tuple 也是关键字，不能作变量名。

关键字不能作变量名 / 参数名 / 字段名。例如 string UA = "..." 会报 E03，应改成 string userAgent = "..."，再用 with UA userAgent。

1.4 最小示例

auto main() {
    return "https://example.com/latest.zip";
}

1.5 访问方式

https://cpps.<你的子域>/?url=<规则文件URL>

参数说明：

  • ?url= 规则文件 URL（必填）
  • ?in= 输入流（可选：纯文本、或 http(s):// 远程文本）
  • ?key= → 内置 key（可用 ?key= 或 ?key0=&key1=；key0 优先于 key；禁止将 key 或 key+纯数字（key0、key123）用作变量名、函数名、结构体名、容器名；结构体字段名不受限；query 参数名同样禁止 key/key0。keyboard 等允许）（可选；可用逗号/空格/换行分隔，连续分隔符合并，首尾可有分隔符；单引号等同双引号；无需大括号；赋值自动 trim）
  • ?in= → 标准输入预置
  • 其它 query 可通过 q_get("名") 读取；内置还有 keyword repoPath tag selector prerelease 及路径段 p1–p4
  • ?run=1 强制跳过表单、立即执行

1.5b 纯前端本地运行（根目录 index.html）

  • 纯前端入口为站点根目录 index.html（原 根目录 index.html）。语法文档在 docs/。
  • 必须通过 http(s) 静态服务加载 ES module；不要用 file://。例如在项目根执行 npx serve . 后打开 /。
  • 无 ?url= 时：可直接贴源代码，或在「规则 URL」页加载远程规则（需 CORS）。
  • 点「运行」后开始执行；标准输入每按 Enter 提交一行，out() 立即显示；点「完成」表示 EOF。
  • get/post 受浏览器 CORS 限制；跨站稳定请求请用 Worker。
  • key / q_get("key") 来自页面 key 输入框。

1.5c <algorithm> 风格函数（详见 §12.8）

  • 作用于 deque 或原生数组，多数为就地修改。
  • 就地：sort(d)、sort(d,"desc")、reverse(d)、unique(d)、iota(d,start)、fill_n(d,n,v)、swap_ranges(d,i,j)
  • 查询：find(d,x) → 下标或 -1；count / min_element / max_element / binary_search / lower_bound / upper_bound / is_sorted / accumulate
  • 排列：next_permutation(d)、prev_permutation(d) 返回 bool
  • 与成员方法区分：a.find(x) 是容器方法；自由函数 find(a, x) 是 algorithm 风格。

1.6 Worker 交互页（按需输入、无缝运行）

  • 打开 ?url= 时先解析规则：检测是否使用 key（含标识符 key 与 q_get("key")）以及标准输入（in() / getchar）。
  • 都未使用 → 直接执行，不显示输入框。
  • 使用了且 URL 中还缺少对应参数 → 只显示需要的框（一个或两个）+ 一个「运行」按钮。
  • 可以留空再点运行：仍会补上 key= / in=（值为空）并执行。
  • 点「运行」后：脚本把 url、run=1 与用到的 key/in（可为空）写入查询串，并用 location.assign 打开结果页。
  • 结果页：Worker 执行规则；若调用了 out()，通过 TransformStream 边执行边推送 HTML 输出区内容。
  • 已带齐参数或带 &run=1 → 跳过表单直接跑。
  • 无 ?url= 访问根路径 → 本语法文档（跟随系统浅色/深色主题）。

示例（幂运算规则，需 key）：

https://cpps.example/?url=https://example.com/cpps.txt
→ 显示 key 输入框 → 填 2^3 → 运行 → 输出 2^3=8

https://cpps.example/?url=https://example.com/cpps.txt&key=2%5E3
→ 已有 key，直接运行

1.7 在 URL 里给 in 换行

  • 查询参数中换行请写成 %0A（CRLF 可用 %0D%0A）
  • 示例：?in=hello%0Aworld → 两行 hello / world
  • 更推荐：页面文本框直接换行，或 ?in=https://... 拉远程文件
  • 注意：& 仍是参数分隔符，正文里的 & 需写成 %26

表达式 返回 说明

i-- 旧值副本（右值） i 减 1

++i 引用（新值） i 先加 1

--i 引用（新值） i 先减 1

  • ++i / --i 返回引用，可链式：++(++i) ✓、(++i) = 5 ✓

4.4 bool 的 ++ / --

全部定义为取反（b = !b）：

bool b = true;

bool nw  = ++b;        // b = true,    nw  = true

4.5 复合赋值

运算符 适用类型

x += y number、string（拼接）、bool

x -= y x *= y x /= y x %= y number、bool

x <<= n x >>= n x &= y x \|= y x ^= y number、bool（整数）

  • 返回左值引用，可链式：(a += 1) *= 2 ✓
  • string 只支持 +=，其他 → E11
  • 位运算操作数必须整数 → E34

4.6 bool 的复合赋值

流程：b 转 number（true=1）→ y 转 number → 运算 → 非零转 true → 赋回。

6. 函数与 return

6.1 辅助函数

number add(number a, number b) { return a + b; }
void log(string msg) { out(msg); }
  • 返回类型显式声明，参数类型显式（不能 auto）
  • 不支持：重载、默认参数、可变参数、函数指针、匿名函数、引用返回值
  • 辅助函数返回类型可为 auto（可不 return）
  • 递归深度上限 100
  • 前向引用允许
  • 有返回类型函数所有路径必须 return（E18）

6.2 auto main()

必须显式写 auto（推荐）或 void（兼容），恰好一个，无参数。不写 / 返回类型不是 auto/void → E14。

6.3 主函数 return

主函数 return 只能返回 URL，body 输出统一用 out。

合法形式：

写法 响应

return "https://example.com/a.zip"; 302

return "example.com/a.zip"; 302（补 https）

return "中文.com/文件.zip"; 302（补 https + punycode + 路径编码）

return "abc.onion/file.zip"; 302（补 http）

return "abc.i2p/download"; 302（补 http）

return "url" with 301; 301

return with 404; 404 + 输出（或流式 200，见 §6.4）

return 404; 404 + 输出

return; 200 + 输出

自然结束 200 + 输出

禁止形式：

写法 错误

return "hello world"; E43（host 含空格）

return "hello" with 200; E44（body 只能 out）

return ""; E43

URL 规范化流程：

1. raw 为空 → E43
2. 解析协议头：http:// 或 https:// 开头（大小写不敏感）→ 协议 + rest
3. 从 rest 提取 host（到第一个 '/' 或 ':' 之前）
4. host 非法字符检查：空白、控制字符、< > " { } | \ ^ [ ] ` @ # ? → E43
5. 端口检查：必须是 1..65535 的整数，否则 E43
6. 协议未定：host 以 .onion / .i2p 结尾 → http，否则 → https
7. new URL(protocol + '://' + rest) → 失败 → E43
8. 返回 url.href（IDN 自动 punycode，路径自动编码）

示例：

字符串 结果

"example.com/a.zip" https://example.com/a.zip

"中文.com/文件.zip" https://xn--fiq228c.com/%E6%96%87%E4%BB%B6.zip

"例子.中国/a" https://xn--fsqu00a.xn--fiqs8s/a

"abc.onion/file.zip" http://abc.onion/file.zip

"abc.i2p/download" http://abc.i2p/download

"example.com/a b.zip" https://example.com/a%20b.zip

"hello world" E43（host 含空格）

"" E43

6.4 out 与流式渲染

out 是 body 输出通道。Worker 版用 TransformStream 边执行边推送；本地版直接追加到页面输出框。

6.4.1 双路响应

脚本行为 响应模式

从未调用 out buffer 模式：脚本执行完后，按 return 决定 302 / 200+body

调用过 out（至少一次） 流式模式：先返回 HTML 壳，每次 out 向输出区追加一段（Worker：TransformStream；本地：DOM/文本框）

6.4.2 buffer 模式（未调 out）

auto main() {
    return "https://example.com/a.zip";     // 302
}

auto main() {
    return with 404;                        // 404（空 body）
}

auto main() {
    return;                                 // 200（空 body）
}

6.4.3 流式模式（调了 out）

auto main() {
    out("step 1\n");      // 客户端立即收到
    // ... 耗时操作
    out("step 2\n");      // 客户端立即收到
    out("step 3\n");      // 客户端立即收到
    return;               // 关闭流
}
  • 响应状态码固定 200
  • Content-Type: text/plain; charset=utf-8（固定）
  • return with N / return N 中的 N 被忽略（已经 200 了）
  • return "url" → 302 跳转（可与 out 同时使用；前端先显示输出再跳转）
  • 出错时：流末尾追加 [error: <message>] 并关闭连接

6.4.4 对比

场景 buffer 模式 流式模式

return "url" 302（可先 out）

return with N N + body 200（N 忽略）

return; / 自然结束 200 + body 200（已推送完）

输出时机 一次性 逐 chunk

Content-Type 可自定义（with header） 固定 text/plain

6.4.5 何时用流式

  • 长耗时脚本：用户想看到进度
  • 大输出：不想全缓冲在内存
  • 否则不调 out，享受 buffer 模式的灵活性（302 / 自定义状态码）

void addOne(number& x) { x = x + 1; }

7. 原生数组

7.1 声明

number a[5];                 // 5 个 number，默认 0
string b[3];                 // 3 个 string，默认 ""
Asset  d[4];                 // 4 个 Asset

number e[n];                 // n 必须已初始化（否则 E36）

number m[3][4];              // 3×4 二维
string t[2][3][4];           // 2×3×4 三维（最高 4 维）
  • 元素类型：number / string / bool / struct 名
  • 不支持元素类型是 deque / set / map
  • 大小必须是已初始化的 number 变量或字面量
  • auto a[5]; → E25

7.2 访问与遍历

number a[5];
a[0] = 10;
out(to_str(a[2]));           // 0

number m[3][4];
m[1][2] = 99;

for (auto x in a) { out(to_str(x)); }              // 一维可范围 for
for (number i = 0; i < 3; i++) {
    for (number j = 0; j < 4; j++) {
        m[i][j] = i * 4 + j;
    }
}

越界 → 运行时 E23。

7.3 限制

  • 无容器方法（push/pop/insert/erase/find/fill/clear）→ E32
  • 元素只能通过下标读写
  • delete a; 释放整个数组；delete a[i]; 不支持

7.4 声明方式对比

声明 是什么

number a[5]; 原生数组，固定 5 个元素

deque<number> a; 动态容器

deque<number> a(5); 容器，初始 size=5，可 push/pop

deque<number> a[5]; 容器组（5 个独立空容器）

number m[3][4]; 原生二维数组

8. 容器

8.1 三种容器；其中 deque<auto> / set<auto> 在 push/insert 时按实参决定元素运行时类型（number/string/bool 可混用）。内置 key（可用 ?key= 或 ?key0=&key1=；key0 优先于 key；禁止将 key 或 key+纯数字（key0、key123）用作变量名、函数名、结构体名、容器名；结构体字段名不受限；query 参数名同样禁止 key/key0。keyboard 等允许） 在花括号形式下为 deque<auto>

类型 说明

deque<T> 双端队列，可重复，支持下标

set<T> 去重，按插入顺序，支持下标

map<K, V> 键值映射

  • deque/set 的 T ∈ number / string / bool / auto / struct 名
  • map 的 K ∈ number / string；V ∈ number / string / bool / struct 名
  • 不支持嵌套 → E19

8.2 声明

deque<number> a = { 1, 2, 3 };
set<string>   s = { "x", "y" };
deque<number> b;              // 空
deque<number> c(5);           // size=5，元素全 0

map<string, number> m;                        // 空
map<string, number> m2 = { "a": 1, "b": 2 };  // 字面量

8.3 deque / set 成员

成员 返回 说明

d[i] T 下标访问，越界 E23

d.size() number 元素个数

d.find(v) number 第一个等于 v 的下标，不存在 -1

d.front() / d.back() T 空 E23

d.push_back(v) / d.push_front(v) void

d.pop_back() / d.pop_front() void

d.erase(i) void 删下标 i

d.insert(i, v) void 在下标 i 处插入

d.clear() void 清空

d.fill(v) void 全部填 v

11. 输入流

本地根页面：运行后在「标准输入」框中每行回车提交一次；按钮「完成」= EOF。Worker 仍可用 ?in= 预置全文。

11.1 输入流来源优先级

  1. 表单字段 in（运行页 POST，可含真实换行）
  2. ?in= 查询参数
  3. 否则 POST / PUT / PATCH 的原始 body（非表单时）
  4. 否则空

11.2 ?in= 规则

1. 读取 ?in= 的值（URL 解码后）
2. 若值匹配 ^https?://（大小写不敏感）
   → 远程 GET 拉取，响应体原文作为输入流
   → 4xx/5xx → E50；大小超 1 MB → E51；SSRF → E27
3. 否则
   → 值本身直接作为文本输入流（大小超 1 MB → E51）

示例：

  • ?in=https://example.com/data → 远程全文
  • ?in=hello%20world → hello world
  • ?in=hello%0Aworld → 两行（换行）
  • ?in=%E4%B8%AD%E6%96%87 → 中文
  • 运行页文本框多行 / 表单 POST → 直接保留换行

注意：查询串里 & 是参数分隔符，正文中的 & 请用 %26。

11.3 游标

输入流有一个读取游标，初始在位置 0。getchar() 和 in() 共享同一个游标。

11.4 getchar()

number c = getchar();
  • 读到字符：返回该字符的 Unicode code point
  • 已到 EOF：返回 -1
  • 不跳过空白，不影响 in 的跳过空白行为
  • 每次调用游标前进 1

11.5 in(x)（cin 风格）

1. 跳过前导空白（' ' '\t' '\n' '\r'）
2. 从当前位置读到下一个空白（或 EOF）为止，得到 token
3. 按 x 的类型转换：
   - number 变量：token → to_num()
   - string 变量：token 直接赋值
   - auto 变量：token 匹配 ^-?\d+(\.\d+)?([eE][-+]?\d+)?$ → number，否则 string
   - bool 变量：token 非空且非 "0" → true，否则 false
4. 游标停在 token 末尾

EOF 时 x 保持原状态（未初始化仍未初始化）。

in(x) 的 x 必须是可声明的变量名，否则 E48。

11.6 混合示例

// 输入流："42,hello,3.14"
auto main() {
    number n;
    string s;
    number pi;

    in(n);                  // 读到 '4' '2' 然后遇到 ',' → n = 42
    getchar();              // 读掉逗号
    in(s);                  // "hello"
    getchar();              // 读掉逗号
    in(pi);                 // 3.14

    out(to_str(n) + " " + s + " " + to_str(pi) + "\n");
    return;
}

12.1 请求

  • 无论服务器返回什么，get/post 永远返回 string
  • 4xx / 5xx 不终止，用 status() 判断
  • 单次请求超时 10s，响应体上限 5MB

12.2 with 通用修饰符（含义由 with 前的函数定义：return→状态码/头/代理；get/post→param/header/UA/proxy；其它函数带 with → E52）

修饰符 请求上下文 return 上下文

with N ✗ E52 ✓ 状态码

with param { ... } ✓ query 参数 ✗ E52

with header { ... } ✓ 请求头 ✓ 响应头

with UA <expr> ✓ User-Agent ✗ E52

with proxy <expr> ✓ 代理前缀 ✓ 重定向 URL 前缀

with { ... }（无关键字） ✓ = with param（兼容） ✗ E52

// 请求上下文
get(url)
    with param { "q": "abc", "page": "1" }
    with header { "Accept": "application/json", "Authorization": "token " + key }
    with UA "Mozilla/5.0"
    with proxy "https://proxy.example/";

// return 上下文
return "https://github.com/a/b/releases/download/v1.0/x.zip"
    with 301
    with header { "Cache-Control": "max-age=3600" }
    with proxy "https://v6.gh-proxy.org/";

规则：

  • 多次 with 合并，同名后者覆盖
  • with param/header 的 value 可以是表达式（header/param 的键名仍是字面量）
  • with 优先级低于 + 等二元运算：return "a" + b with 302; = return ("a" + b) with 302;
  • with 含义由前面的函数决定：get/post → param/header/UA/proxy；return → status/header/proxy；否则 E52
  • with proxy 拼接规则：最终 URL = proxy 前缀 + 原 URL，SSRF 检查的是最终 URL
  • 响应头不允许 Location / Content-Length / Transfer-Encoding → E53
  • 多个 with proxy 后者覆盖前者

15.4 进制转换器（流式版）

// dsl: 14
// 访问：?url=...&n=255&base=16

string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

string digitChar(number d) {
    if (d < 0 || d >= 36) return "?";
    return regex(DIGITS, "^.{" + to_str(d) + "}(.)");
}

string toBase(number n, number base) {
    if (base < 2 || base > 36) return "ERR_BASE";
    if (n == 0) return "0";
    bool neg = false;
    if (n < 0) { neg = true; n = -n; }
    number num = floor(n);
    string result = "";
    while (num > 0) {
        number r = num % base;
        num = floor(num / base);
        result = digitChar(r) + result;
    }
    if (neg) result = "-" + result;
    return result;
}

auto main() {
    string nStr    = q_get("n");
    string baseStr = q_get("base");

    if (nStr == "") {
        out("用法: ?n=值&base=目标进制\n");
        return;
    }
    if (baseStr == "") {
        out("缺少 ?base=\n");
        return;
    }

    number base = to_num(baseStr);
    if (base < 2 || base > 36) {
        out("进制必须在 2-36 之间\n");
        return;
    }

    number value = to_num(nStr);
    string result = toBase(value, base);
    out(result + "\n");
    return;
}

注意：这里全用 out + return;，会走流式模式（状态码 200）。

16. 常见坑

坑 1：main 可为任意返回类型（auto/void/bool/number/string/…）

// main() { }              // ✗ E14
auto main() { }             // 返回 string 才跳转 URL
bool main() { return 2; }   // → true
number main() { return 1; }

坑 2：return 只返回 URL

// return "hello";         // ✗ E43
// return "hello world";   // ✗ E43
return "example.com/a";    // ✓ 302

坑 3：out 和 return "url" 可以同用

auto main() {
    out("hello\n");                          // 触发流式
    return "https://x.com/a";                // ✗ E47（流式模式可跳转）
}

正确做法：要 302 就别 out；要输出就别 return "url"。

坑 4：流式模式状态码固定 200

auto main() {
    out("error\n");
    return with 500;        // 实际返回 200（流式已激活）
}

正确做法：错误信息放 out，状态码只能是 200（流式限制）。或者不用 out，用 return with 500; 走 buffer 模式。

坑 5：中文域名的点必须是半角

return "中文.中国/x";       // ✓
// return "中文。中国/x";   // ✗ E43（全角句号）

坑 6：.onion / .i2p 默认补 http

return "abc.onion/a";      // → http://abc.onion/a
return "abc.i2p/a";        // → http://abc.i2p/a

坑 7：in 从输入流读，不是 query

// v13 之前
in(n);                    // ✗ 现在从输入流读，GET 请求下是空的
// 正确
number n = to_num(q_get("n"));    // ✓ 从 query 读

坑 8：?in= 的值是 URL 还是文本

?in=https://example.com/data     → 远程拉取
?in=hello%20world                → 文本 "hello world"
?in=                             → 空文本

坑 9：位运算操作数必须整数

number a = 3.5;
// a & 1;                  // ✗ E34

坑 10：原生数组不能 push

number a[5];
// a.push_back(10);        // ✗ E32

坑 11：a(n) vs a[n] vs T a[n] vs map

number arr[5];             // 原生数组，5 个 number
deque<number> c(5);        // 容器，size=5，可 push/pop
deque<number> g[5];        // 容器组，5 个独立空 deque
map<string, number> m;     // 键值映射，空

坑 12：map 下标不存在的 key 返回默认值

map<string, number> m;
m["x"] = 10;
out(to_str(m["y"]));       // 0（不存在返回 V 默认值，不插入）

坑 13：struct 不能循环引用

struct A { number x; };
struct B { A a; };         // ✓ 单向嵌套
// struct S { S inner; };  // ✗ E40（自引用）

坑 14：未初始化变量读 → E36

number x;
// out(to_str(x));         // ✗ E36
x = 5;
out(to_str(x));            // ✓

坑 15：auto 不能推 bool

// auto ok = true;         // ✗ E25
bool ok = true;            // ✓

坑 16：除法是浮点

out(to_str(7 / 2));        // "3.5"
out(to_str(floor(7 / 2))); // "3"

坑 17：容器组 / 多维数组不能范围 for

deque<number> g[3];
// for (auto x in g) { }   // ✗ E30
for (number i = 0; i < g.size(); i++) {
    for (auto x in g[i]) { }  // ✓ 内层是单容器
}

坑 18：map 遍历迭代变量是 key

map<string, number> m = { "a": 1, "b": 2 };
for (string k in m) {
    out(k + " = " + to_str(m[k]) + "\n");
}

坑 19：右移是算术右移

number x = -12;
out(to_str(x >> 1));       // -6

坑 20：++i 返回引用，i++ 返回副本

number i = 5;
++(++i);                   // ✓ i = 7
// (i++)++;                // ✗ E45
(++i) = 100;               // ✓ i = 100

坑 21：bool 的 ++ / -- 是取反

bool b = true;
b++;                       // b = false

坑 22：key 不可修改；花括号形式为 deque

// key = "new";            // ✗ E49
if (key == "") { ... }     // ✓ 读取（字符串形式）
// ?key={1,"abc",false}
// 直接写 key 等价于 key[0]；下标用 key[1]、key[2]
// 关键字 UA/with/string 等不能当变量名 → E03

坑 26：不要用关键字当变量名

// string UA = "Mozilla";           // ✗ E03
string userAgent = "Mozilla";       // ✓
get(url) with UA userAgent;         // ✓

坑 27：in 换行要用编码或表单

// URL:  ?in=line1%0Aline2
// 页面：文本框直接回车，再点「运行」

坑 28：本地版 get/post 受 CORS 限制

// 根目录运行页里 get("https://other.com/...") 若对方无 CORS 会失败
// 需要稳定跨站请求时用 Worker：/?url=规则地址

坑 29：file:// 打不开模块

// 请在含 index.html 与 src/ 的根目录 npx serve .，打开 / 与 /docs/

坑 23：with proxy 不叠加

get(url) with proxy "https://a.com/" with proxy "https://b.com/"
// 最终用 b.com

坑 24：响应头不能写保留字段

// return "url" with 302 with header { "Location": "x" };  // ✗ E53

坑 25：规则文件不要求 .txt 扩展名

?url=https://example.com/rule          ✓ 合法
?url=https://example.com/rule.txt      ✓ 合法
?url=https://example.com/rule.json     ✓ 合法（内容会被当文本解析）
